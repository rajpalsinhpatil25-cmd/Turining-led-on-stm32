# Turning-an-LED-On-STM32
A simple embedded systems project demonstrating how to turn on an LED using an STM32 microcontroller.
---

## 📌 Project Overview

This project explains how to:

- Configure GPIO pins on STM32
- Set a GPIO pin as Output
- Turn an LED ON
- Understand the basic structure of an embedded C project

It is designed as a beginner-friendly introduction to STM32 development.
